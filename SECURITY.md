# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately by emailing **support@firearmstudio.com**.

Please do **not** open a public GitHub issue for security vulnerabilities -
this gives attackers a head start before a fix is available.

Include as much detail as you can: steps to reproduce, affected version/commit,
and potential impact. We'll acknowledge your report and work with you on a fix.

## Supported Versions

Only the latest version on the `main` branch is supported with security
fixes. There are no maintained older release branches.

## Response Time

We aim to acknowledge reports within **5 business days** and to provide an
initial assessment or fix timeline within **10 business days**. Timelines may
vary depending on severity and complexity.
